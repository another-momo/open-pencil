# Task: 装饰素材管线（生图-抠图-贴图路线）

日期：2026-08-12（立项，cutout 工具已落地三版迭代）
状态：阶段二——profile 接线完成，待端到端冒烟
范围：`packages/core/src/tools/marketing/cutout.ts` + `cutout-pure.ts`、`tools/marketing-library/src/generate.ts`（promo_event_v1）、`public/default-library.fig`、对应测试
设计依据：`docs/research/2026-08-11-design-technique-distillation-map.md`（§10-§12，装饰词汇/案例解剖/管线设计）+ 万科促销长图参考案例解剖
分支：`feature/decor-cutout-experiment`（worktree `open-pencil-decor/`）

## 背景与目标

端午冒烟与万科参考案例共同暴露的内容层问题：**纯矢量装饰太干净 = UI 感**；设计感来自质感（笔触肌理、贴纸白边、胶带虚线边），而质感是生图模型的主场。

本 task 验证的命题：

> 以 hero 为风格锚点生成绿幕装饰套图 → 程序抠图 → 贴入对应槽位（比例失配时以抠出件为参考图按槽位重生），能否让内容层从"UI 感"跨到"设计感"，且全流程对 agent 零几何/零像素判断负担？

## 核心路线（唯一在研路线）

```
hero 生成（Phase 2.5 既有）
→ compose_backdrop 处理背景（场景入 BackgroundLayer + 采样渐变）
→ 装饰套图生图（references 含 hero —— hero 是全图唯一风格锚）
→ cutout（角点实测幕色 → 边缘洪水填充 → despill 2px 带 → 腐蚀 → 连通域切分）
→ look 验证
→ Phase 3 内容填充时把装饰件贴入白名单槽位（标题垫层/角标/促销标签）；
  比例失配 → 以抠出件为参考图按槽位尺寸重生（仍绿幕）→ 再抠 → 填充
  （有界 ≤2 次；仍不符取最接近 + note 声明，不粉饰不死循环）
```

**三条不变量**：

1. **永不放大**——显示尺寸 ≤ 素材原生尺寸（critique 可判）
2. **hero 是唯一风格锚**——一切装饰生图（套图/单张重生）都带 hero 参考图
3. **比例失配走闭环重生**——不拉伸、不祈祷 prompt，参考图锚风格 + 请求尺寸锁比例

## 已落地（本分支现状）

- `cutout` 工具（v3）：角点采样定幕色（不信任 #00FF00 字面值）/ 洪水填充（主体内部含幕色不被吃，薄荷绿案例）/ despill 限 2px 边缘带（深前景免疫）/ 连通域切分（越格元素成单件，grid 参数已删，改 `expected` 数量校验）/ 反静默 WARNING 体系（背景不均、被困背景、数量不符）
- `promo_event_v1` profile：首个接装饰管线的品类 profile（促销/活动 R0 样板），Phase 2.5 五步配方含套图生成 + cutout 调用
- 测试：cutout 31 case（纯函数 20 + 工具层 11，mock CanvasKit），全套件 200/200 绿

## 素材清单（生图路线，按槽位）

| 件                                       | 槽位                 | 形态                                                               |
| ---------------------------------------- | -------------------- | ------------------------------------------------------------------ |
| 马克笔笔触底纹带                         | 小节标题垫层         | 套图行式件 / 失配走闭环                                            |
| 爆炸贴/星爆徽章（空白胚）                | 紧迫感标签、卖点角标 | 套图方格件                                                         |
| 胶带标签（微旋转、虚线边）               | 信息块角标           | 套图方格件                                                         |
| 箭头/指引、星星/闪光、角花、风格化小图标 | 点缀                 | 套图方格件                                                         |
| 卡片底纹面板、分区底带                   | 内容容器底           | 同走绿幕抠图（圆角面板在绿幕上生成，抠出后透明圆角落在任何背景上） |
| IP 吉祥物                                | 品牌位               | 单张生成 + 抠图，抠出后入库复用                                    |

**永不进入本路线**：带文字的件（文字永远矢量，徽章只生空白胚）；QR/Logo/真实商品（用户素材区）；复杂背景主体照（模型级分割是另一条路线）；软边半透明（烟/光/雾——生图内化，α 解混欠定不可可靠抠取）。

**移出本路线（研究记录保留在蒸馏地图）**：矢量合成装饰（AI 直写矢量质量低，若要启用需专项的约束引导研究，属单独路线）。

## Prompt 契约（套图）

- 纯绿幕 `#00FF00`（主体含绿时换品红 `#FF00FF` 并显式传 chroma）、无投影、硬边、网格均匀间距、**无文字**、die-cut 白边（辅助抠图）
- **references 必须含 hero**
- 方格套图（2×3/3×3）装紧凑件；行式套图（1×N）装宽扁件（"4 条横幅上下排列各撑满整宽"）
- 冒烟验证双 prompt 与五项评估清单见蒸馏地图 §12.7

## 验证（promo 端到端冒烟）

用 promo_event_v1 做一张真实活动长图，判据：

| #   | 条目         | 通过判据                                                          |
| --- | ------------ | ----------------------------------------------------------------- |
| 1   | 管线走通     | 生场景 → 生套图（带 hero 参考）→ cutout → compose_backdrop → look |
| 2   | 小节标题质感 | 笔触底纹垫层，**不是**干净圆角矩形                                |
| 3   | 贴纸入位     | 抠出件贴进设计槽位，不停留在套图下方                              |
| 4   | 风格一致     | 装饰件与 hero 同风格（hero 锚定生效）                             |
| 5   | 密度纪律     | 每屏贴纸 ≤3、每节类型 ≤2                                          |
| 6   | 功能件真实   | QR 来自素材区，未被生成                                           |
| 7   | 比例处理     | 失配件走了参考重生而非拉伸                                        |

## 明确不做

- 矢量装饰路线（单独研究线）
- 主体物/复杂背景抠图（模型级分割，另一路线）
- `prepare_decor` 闭环编排工具（远期——先看 agent 按 profile 手工走环的失败模式再工具化）
- critique 判据自动化（放大率/文字带方差/装饰密度——随 critique 工具统一做）

## 结论去向

冒烟结果按 `knowledge/methodology.md` §7 归档 error-catalog 新一轮。两种结局：

- **成效明显** → 管线转进 marketing 正典（profile 词汇库定型），评估 prepare_decor 工具化；装饰管线写入 l2-agent-mode §2.1 Phase 2.5
- **成效不明显** → 记录失败模式（生图一致性？抠图质量？入位判断？），按"是否确定性可代码化"分流
