# 设计技巧蒸馏地图：非设计师团队的可工程化设计知识研究

日期：2026-08-11
类型：survey（外部设计知识综述 + 蒸馏路径规划）
背景：海报感实验证明了"蒸馏"路径成立（把长图背景技巧蒸馏为确定性工具 `compose_backdrop`），但团队无设计师背景——"哪些技巧值得蒸馏、从哪里蒸馏"需要系统化研究，不能靠临场灵感。
范围：长图全品类（活动预告 / 月报战报 / 公众号长文 / 知识卡片 / 流程时间轴 / 对比测评 / 详情页等）。

> **本研究的定位**：为品类扩展与工具演进提供"技巧候选清单 + 来源地图 + 蒸馏工作流"。每条技巧标注蒸馏形态（工具 / profile / critique 判据 / prompt），落地动作需另开 task 承接。

## 1. 蒸馏的四层框架（方法论复述）

一条设计技巧到手，按确定性程度分流到四层之一：

| 层 | 判定 | 载体 | 实例 |
|---|---|---|---|
| **工具** | 几何/采样/拼接可确定性计算 | 新工具（compose_* 家族） | hero 底 100px 平静带 + fade 藏缝 → `compose_backdrop` |
| **profile** | 风格选择/数值区间/反模式 | profile 三段式 | 字阶区间、影调-字色配对规则、Anti-identity |
| **critique 判据** | 可自动计算的过/不过检查 | 未来 critique 工具 | 接缝像素差分、标题带对比度 |
| **prompt/模型** | 需内容理解，不可判定 | 工作流规则 | 视觉隐喻选择、文案质量 |

**分流纪律**（本项目反复实证）：能把守的东西绝不留給 prompt——prompt 层是注入可靠性排序的次低档（`knowledge/methodology.md` §1）。

## 2. 蒸馏来源地图（从哪里蒸馏）

按"可蒸馏度 × 可信度"排序的五类来源：

| # | 来源 | 内容形态 | 可蒸馏度 | 用法 |
|---|---|---|---|---|
| S1 | **经典设计理论** | Müller-Brockmann《Grid Systems》（网格/flowline/hangline）、modular type scale（base × ratio^n）、Bringhurst 比例论 | ★★★★★（本身就是数学） | 直接翻译成工具参数与 profile 区间 |
| S2 | **中文排版实战生态**（公众号/小红书教程） | 网易屏读排版秘诀、135 编辑器/壹伴排版原则、Canva 设计学院 | ★★★★（带具体数值：字号/行距/边距） | 直接进 profile 数值档；注意其数值面向"屏读长文"而非"海报"，需按品类修正 |
| S3 | **优秀作品逆向工程** | 获奖海报/爆款长图的量化拆解（量边距、字阶比、留白率） | ★★★★（实证但需人工读图） | 即 gc-minimal-zine-poster 方法论借鉴的路径；候选：每品类拆 5-10 张公认好图，量出数值分布作为 profile 区间与 critique 阈值的校准依据 |
| S4 | **竞对产品的内置规则** | Napkin 的 30+ 视觉框架库、稿定/创客贴模板、Canva 模板 | ★★★（模板=品类技巧的固化） | **模板解剖**：稿定一张爆款模板就是一份"品类版面配方"，逆向出 section 结构/字阶/配色角色 |
| S5 | **本项目 error-catalog** | 冒烟失败反推（R5-1 影调事故 → 配对规则） | ★★★★★（最贴本系统） | 已是成熟机制，继续跑 |

**注意**：S2 的中文教程数值（14-15px 正文、1.75 倍行距）面向 1080px 宽的屏读长文；S1 的海报原则面向远观场景。本项目画布 750px 宽的长图介于两者之间——**所有外部数值进 profile 前必须经过本项目冒烟校准**，不可照抄。

## 3. 技巧清单（按设计层级组织）

每条标注：量化规则 / 蒸馏形态 / 来源 / 目标品类。✅ = 已在系统中落地。

### A. 结构层（骨架与动线）

| 技巧 | 量化规则 | 蒸馏形态 | 来源 | 品类 |
|---|---|---|---|---|
| 三段动线结构 | 顶部 ~30% 建立预期（标题+摘要）→ 中部 ~50% 信息主体 → 底部 ~20% 行动引导 | profile（骨架契约） | S2 公众号代运营实战 | 全部长图 |
| 一屏一信息点 | 单屏只承载一个核心信息 | profile + critique（信息密度） | S2 | 全部 |
| 视觉锚点节奏 | 每 3-4 屏一个视觉锚点（色块/图标/加粗句），防阅读疲劳 | profile | S2 | 长文/月报 |
| 三级信息分层 | hook（远观可见）/ context（近观）/ fine print（细看），位置权重上重下轻 | profile + critique | S1 海报原则 | 全部 |
| 网格与 hangline | 边距 + 列 + flowline；标题/主图挂高 flowline | 工具（骨架生成时计算对齐） | S1 Müller-Brockmann | 月报/详情页 |

## 5. 对本项目指标体系的校准输入

外部来源为暂缓的指标重构提供了两个实证锚点（留待 critique 阶段使用）：

1. **字阶比**：专业海报指南的一致口径是主标题 : 次级 = **3:1 ~ 5:1**（S1 多源一致）——评审一的"6-10×"偏激进，端午冒烟实测 3.7× 实际落在专业区间内。未来 critique 的字阶判据建议取 **Display/Body ≥ 3**（语义角色比，非 max/median）。
2. **squint test（眯眼测试/缩略图测试）**：所有海报指南的共同验收法——缩到缩略图尺寸仍能说出主题与第一看点。这正是 look 工具可以自动化的判据（缩略图导出 + vision 问答），比几何代理指标更接近"海报感"本体。

## 6. 蒸馏工作流（怎么持续蒸馏）

```
来源(S1-S4) → 技巧候选 → 四层分流(§1) → 实现 → 冒烟 → error-catalog 反馈 → 修正/新候选
                  ↑                                            ↓
         优秀作品逆向拆解(S3) ←——— 冒烟中发现的"做不到的" ————┘
```

- **逆向拆解法（S3 操作化）**：每品类选 5-10 张公认好图 → 用 look/describe 量边距、字阶比、留白占比、色数 → 数值分布写进 profile 区间（而非拍脑袋）→ 同时产出 critique 阈值的参考分布
- **模板解剖法（S4 操作化）**：稿定/创客贴的品类模板 = 现成的版面配方——section 结构、字阶角色、配色分配直接可拆
- **纪律**：一条技巧只有进了工具/profile/判据之一才算蒸馏完成；写在 prompt 里的技巧默认会失效（方法论 §1）
