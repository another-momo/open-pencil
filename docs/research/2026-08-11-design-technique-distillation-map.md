# 设计技巧蒸馏地图：非设计师团队的可工程化设计知识研究

日期：2026-08-11
类型：survey（外部设计知识综述 + 蒸馏路径规划）
背景：海报感实验证明了"蒸馏"路径成立（把长图背景技巧蒸馏为确定性工具 `compose_backdrop`），但团队无设计师背景——"哪些技巧值得蒸馏、从哪里蒸馏"需要系统化研究，不能靠临场灵感。
范围：长图全品类（活动预告 / 月报战报 / 公众号长文 / 知识卡片 / 流程时间轴 / 对比测评 / 详情页等）。

> **本研究的定位**：为品类扩展与工具演进提供"技巧候选清单 + 来源地图 + 蒸馏工作流"。每条技巧标注蒸馏形态（工具 / profile / critique 判据 / prompt），落地动作需另开 task 承接。

## 1. 蒸馏的四层框架（方法论复述）

一条设计技巧到手，按确定性程度分流到四层之一：

| 层 | 判定 | 载体 | 实例 |
|---|---|---|---|
| **工具** | 几何/采样/拼接可确定性计算 | 新工具（compose_* 家族） | hero 底 100px 平静带 + fade 藏缝 → `compose_backdrop` |
| **profile** | 风格选择/数值区间/反模式 | profile 三段式 | 字阶区间、影调-字色配对规则、Anti-identity |
| **critique 判据** | 可自动计算的过/不过检查 | 未来 critique 工具 | 接缝像素差分、标题带对比度 |
| **prompt/模型** | 需内容理解，不可判定 | 工作流规则 | 视觉隐喻选择、文案质量 |

**分流纪律**（本项目反复实证）：能把守的东西绝不留給 prompt——prompt 层是注入可靠性排序的次低档（`knowledge/methodology.md` §1）。

## 2. 蒸馏来源地图（从哪里蒸馏）

按"可蒸馏度 × 可信度"排序的五类来源：

| # | 来源 | 内容形态 | 可蒸馏度 | 用法 |
|---|---|---|---|---|
| S1 | **经典设计理论** | Müller-Brockmann《Grid Systems》（网格/flowline/hangline）、modular type scale（base × ratio^n）、Bringhurst 比例论 | ★★★★★（本身就是数学） | 直接翻译成工具参数与 profile 区间 |

## 5. 对本项目指标体系的校准输入

外部来源为暂缓的指标重构提供了两个实证锚点（留待 critique 阶段使用）：

1. **字阶比**：专业海报指南的一致口径是主标题 : 次级 = **3:1 ~ 5:1**（S1 多源一致）——评审一的"6-10×"偏激进，端午冒烟实测 3.7× 实际落在专业区间内。未来 critique 的字阶判据建议取 **Display/Body ≥ 3**（语义角色比，非 max/median）。
2. **squint test（眯眼测试/缩略图测试）**：所有海报指南的共同验收法——缩到缩略图尺寸仍能说出主题与第一看点。这正是 look 工具可以自动化的判据（缩略图导出 + vision 问答），比几何代理指标更接近"海报感"本体。

## 6. 蒸馏工作流（怎么持续蒸馏）

```
来源(S1-S4) → 技巧候选 → 四层分流(§1) → 实现 → 冒烟 → error-catalog 反馈 → 修正/新候选
                  ↑                                            ↓
         优秀作品逆向拆解(S3) ←——— 冒烟中发现的"做不到的" ————┘
```

- **逆向拆解法（S3 操作化）**：每品类选 5-10 张公认好图 → 用 look/describe 量边距、字阶比、留白占比、色数 → 数值分布写进 profile 区间（而非拍脑袋）→ 同时产出 critique 阈值的参考分布
- **模板解剖法（S4 操作化）**：稿定/创客贴的品类模板 = 现成的版面配方——section 结构、字阶角色、配色分配直接可拆
- **纪律**：一条技巧只有进了工具/profile/判据之一才算蒸馏完成；写在 prompt 里的技巧默认会失效（方法论 §1）

## 8. 活动宣传品类专章（2026-08-11 第二轮深挖）

首发品类的专项研究。**活动宣传长图与其他长图的本质区别是转化导向**——它不是被"阅读"的，是被"行动"的。技巧清单按转化漏斗组织：停（hook）→ 读（信息）→ 信（利益/紧迫）→ 动（CTA）。

### 8.1 品类本质与验收标准的差异

| 维度 | 活动宣传 | 阅读型长图（公众号长文/月报） |
|---|---|---|
| 成功标准 | 报名/扫码/到场 | 读完率 |
| 时间预算 | 第一眼 <1 秒决定停不停，3 秒内找到"怎么参与" | 3-5 分钟阅读 |
| 信息策略 | **≤3 条关键信息**（主优惠/截止时间/适用范围），其余进详情页 | 完整承载 |
| 收尾 | **必须有行动区**（QR/报名），底部 20% | 引导关注即可 |

**端午冒烟的缺口实证**：本次端午长图交付到"活动信息区"就结束了——没有行动区、没有 QR、没有报名引导。按活动宣传的标准这是一次**未完成的交付**（信息齐备但漏斗没到底）。验收清单因此必须加一条：**行动区存在且可扫描**。

### 8.2 行动区（CTA）技巧——本品类最高优先级

| 技巧 | 量化规则 | 蒸馏形态 | 来源 |
|---|---|---|---|
| 一图一行动 | 每张海报只链接一个行动（报名/购票/领券），两个码 = 犹豫 = 流失 | 工作流契约（需求单收一个 CTA）+ critique | QRCodeChimp 指南 |
| QR 位置 | **底部 1/3，通常右下角**（视线终点=行动点）；距边缘 ≥1.5cm 等效；避开折痕/平台 UI 遮挡区 | profile（行动区版式契约） | QRCodeChimp / 创客贴转化文 |
| QR 尺寸 | **10:1 原则**——码宽 ≥ 扫描距离的 1/10。750px 画布按手机 2x 显示估算 ≈120-160px（**待本项目冒烟校准**） | profile + critique | QRCodeChimp |
| QR 静区与配色 | 码周围留 ≥1 模块宽的空白；深色码配浅底，不反色；码后不叠渐变/照片/纹理 | critique（静区检查可做：码周围纯色检测） | QRCodeChimp |
| 行动说明文字 | 码下必有短说明（"扫码报名"），无说明的码扫描率显著更低 | profile + critique | QRCodeChimp |
| 按钮文案 | 直接行动语（"立即报名"/"免费领取"），禁止模糊语（"点击这里"） | profile（Tone 节） | 创客贴 |
| QR 素材来源 | **QR 必须真实可扫**——用户素材（需求单素材区），绝不生成 | 工作流契约（CP1/CP3 询问） | 本项目方法论（AI 生图不可信场景） |

### 8.3 信息层技巧（"读"的阶段）

| 技巧 | 量化规则 | 蒸馏形态 | 来源 |
|---|---|---|---|
| 主标题版面占比 | 活动名占版面高度 **15-20%**（社群缩略图里也必须可读） | critique（标题高度占比） | Ivory Design |
| 活动信息五要素 | 主题 / 时间 / 地点 / 参与方式 / 亮点——"信息清单法"逐条核对不遗漏 | **需求单协议**（结构化收集）+ validate/critique | 美图设计室 |
| 时间写法规范 | 日期+星期+时段短格式（"6.16 周二 12:40"），不写长句 | profile + critique | 树叶云 |
| 亮点短句化 | 图标+短文案、"• 10组嘉宾"符号分隔；不用长段落 | profile（信息块契约） | 树叶云/美图 |
| 时间地点字重 | 16-18px Medium 字重略高（扫读友好，高于正文半档） | profile（字阶档位） | Figma 海报教程 |
| 信息模块组件化 | 时间/地点/名额打成固定间距的 auto-layout 模块，换内容不乱 | 工具（远期：compose_infoblock 或模板化 section） | Figma 教程（Shift+A 思想） |

### 8.4 利益与紧迫层（"信"的阶段）

| 技巧 | 量化规则 | 蒸馏形态 | 来源 |
|---|---|---|---|
| 数字主导 | 用户最在意的**数字**放最大（"前 20 名"的 20、"减 50"的 50）；具体数字不模糊（"满300减150"而非"优惠多多"） | profile + critique（数字字号对比） | 图叮/创客贴/电商美工网多源 |
| 紧迫感元素 | 倒计时 / 限量（"前100名"）/ 截止日——**品类化反模式**：促销 profile 允许，水彩/editorial 的 Anti-identity 继续禁止 | profile 分化（各品类 Anti-identity 差异化） | 创客贴（限时可+30%转化） |
| 社交货币 | 互动钩子 / 用户证言（"1000+ 人已报名"） | profile（Variable 轴） | 创客贴 |
| 情绪配色 | 行业-配色映射（科技=蓝黑、食品=橙红、文艺=莫兰迪、儿童=明黄） | CP1 方向提案的候选池 | 美图/树叶云多源 |

### 8.5 一致性与规格层

| 技巧 | 量化规则 | 蒸馏形态 | 来源 |
|---|---|---|---|
| 活动视觉一致性 | 同一活动全物料一套主色+字体（多触点记忆积累）；固定 Logo 位置/主色/优惠标签样式 | 工作流（系列任务继承 profile） | 有赞/图叮 |
| 安全边距 | 文字与关键卖点压安全区以内（平台 UI 高发遮挡区：上下两端/四角） | critique（边缘安全区检查） | 图叮（平台规范） |
| 社群版 vs 印刷版 | 社群 1080 宽 RGB；印刷 300dpi CMYK——一次设计多版输出 | 远期（导出管线） | Ivory Design |

### 8.6 排版基础层（Figma 教程的硬数值，可直接校准 profile）

12 列网格（margin 80 / gutter 24，750 宽等比折算）| 间距取 8 的倍数 | 字阶三层 64-88 / 20-28 / 14-16px | 标题行距 1.05-1.2 / 正文 1.4-1.7 | 主标题区 ≥20% 画面高度 | 深底正文不纯白（#EDEDED 更耐看）| 重要信息只锁 1-2 条主轴线（左对齐稳、居中更海报感但需更严间距）。

### 8.7 优先级结论（活动宣传品类的蒸馏顺序）

1. **行动区契约（最高优先）**——端午冒烟证明缺口真实存在；且答案的一半已在库里：**退役的 CTABar 组件（含 qrCode 只读槽）正是行动区的现成骨架**。建议路径：CTABar 不进 anchor 机制复活，而是转为 **profile 驱动的行动区版式**（Phase 2.5 或 Phase 3 末段按品类契约渲染），QR 素材走需求单素材区。验收加"行动区存在且 QR 静区/尺寸/说明达标"。
2. **活动信息块契约**（五要素 + 时间格式 + 亮点短句化 + 时间地点字重）——纯 profile 层，零工具成本，端午 ActivitySection 已是雏形，明文化即可。
3. **数字主导与紧迫感品类化**——促销向 profile（新）与现有水彩/editorial 的 Anti-identity 分化；这是 profile 系统"按品类分化反模式"的第一个实例，方法论价值高。
4. **信息模块组件化 / 安全边距检查 / 系列化多版**——中期，随 critique 工具与系列任务能力一起做。

## 9. 美学层专章："好看"的可执行分解（2026-08-11 第三轮深挖）

前两轮蒸馏的是**功能性技巧**（结构/转化/排版）——它们让设计"对"。但用户的终极问题是"好不好看"。`compose_backdrop` 的本质就是一次"让背景更好看"的动作化；本章把"美"按可执行性拆成四层，回答"还有哪些好看可以被动作化"。

### 9.1 美的四层可执行性分级

| 层 | 判定 | 载体 | 例子 |
|---|---|---|---|
| **可计算的美** | 纯数学，输入确定输出唯一 | 工具/纯函数 | 色彩和谐（色轮几何）、模数字阶、网格对齐、60-30-10 比例 |
| **可配方化的美** | 固定步骤食谱，无创作判断 | compose_* 工具 / render 配方 | 弥散光、噪点、双色调、光影 token、叠压 |
| **可声明的美** | 是风格选择而非计算 | profile Variable 轴 | 和谐类型、质感有无、冷暖、松紧 |
| **只能判断的美** | 整体审美不可分解 | critique / squint test | "这张图好不好看" |

### 9.2 色彩和谐：从"采样一个色"到"派生整盘色"——最大的可计算红利

**七种经典和谐全部是色轮几何**（complementary 180° / analogous ±30-60° / split-complementary 150°/210° / triadic 120° / square 90° / monochromatic 明度阶梯 / near-complementary ±20-30°），叠加三条比例与明度纪律：

- **60-30-10 角色分配**：60% 主色定调、30% 辅助色出结构、10% 强调色被记住；最艳的永远放 10%（比例颠倒是最常见的"刺眼"根因）
- **muted 主色 + vivid 强调**：互补色双满强度是 GeoCities；tints（加白）/shades（加黑）/muting（拉灰）三个旋钮降音量
- **80% 中性色洞察**：版面 80% 是中性色承载，冷暖温度必须一致（暖中性配暖盘、冷中性配冷盘，混温是"说不上来的别扭"的根因）

**接入点（关键）**：`sample_hero_color` 已经产出种子色（端午实测 #EFEDD9），色彩管线目前止步于"采样中间 stop"。但种子色 → 和谐派生是纯数学——管线可以自然延伸：

```
采样种子色 → harmony 类型（profile Variable 轴选定）→ 60-30-10 角色分配
          → 全图色票（ground / wash / accent / ink）→ WCAG 对比度校验
```

**这消灭最后一个"模型编颜色"的残留**：CP1 方向提案的三个方向色盘目前由模型现场编 hex（端午 log 可见）。工具形态：`derive_palette(seed_hex, harmony)` 纯函数、可测试；direction 的差异化从"编不同 hex"变为"选不同 harmony 类型"——可归因、可复现。

### 9.3 质感：弥散光配方实证"氛围 = 确定性合成"

弥散光（阿里/网易 2021 起的大厂趋势风，弥散渐变+噪点）的教程配方拆解后**每一步都是矢量原生操作**：

```
3-7 个调色盘色椭圆（对角线或三分位放置，同色系 alpha 100%→55% 渐变）
→ LAYER_BLUR ~80px（虚实结合：保留部分锐边轮廓）
→ NOISE fill 叠加 ~5% 单色噪点（复古/胶片颗粒）
→ 可选：边缘内发光收拢 + 半透明高光点（fill 60%）
```

**引擎适配已核实**：`NOISE` fill 类型、`LAYER_BLUR`/`BACKGROUND_BLUR` effect、4 种渐变全部存在于 scene-graph 类型系统——`compose_ambient`（氛围层工具）零模型依赖、零新引擎工作。同类可配方化质感：噪点单色叠加（5%）、双色调映射（duotone，亮度域两色映射）、光晕 token。

**诚实的边界**：弥散光是**流行风格**而非永恒法则——会过时。但这恰好印证 profile 体系的价值：风格会过时，**蒸馏机制不过时**；过时的风格退役一个 profile 即可，工具与方法论沉淀留下。

### 9.4 深度与构图（可配方化/可判定）

- **前中后景三层** + 透明度阶梯（实→60%→光晕）——叠压感的纵深版（评审一 P4 三槽的美学根据）
- **三分法 / 黄金比 / hangline**：主视觉重心落在三分位而非几何中心——构图工具（远期）或 critique 判据（重心象限检测）
- **破格至多一处**：倾斜/出血/越界元素计数 >1 即报警——critique 可算
- ** squint test 自动化**（重申）：缩略图导出 + vision 问答"第一眼看到什么"——"整体好看"的唯一可操作判据

### 9.5 风格 = 配方的组合装配

美学层给 profile 系统提供了一个扩展公式：

**一个新风格 profile = 质感配方 × 色彩和谐类型 × 排版纪律 的组合**

- 弥散风 = 弥散光配方 + 撞色互补 + 大字重对比
- 新中式 = 水彩晕染（生图内化 ✅）+ 单色系/邻近色 + 大留白 + 竖排/印章位
- 酸性风 = 噪点杂色 + 高饱和撞色 + 锐角几何
- 杂志风（editorial ✅）= 无质感 + 单 accent + 边距纪律

profile 的规模化生产因此不再是"写散文"，而是从技巧清单**装配**——每个新 profile 的发明感下降、可归因性上升。

### 9.6 美学层蒸馏优先级

| # | 候选 | 形态 | 理由 |
|---|---|---|---|
| 1 | **`derive_palette`（种子色 → 全色票）** | 纯函数工具 | 色彩管线已有一半（采样），补上派生即闭环；直接消灭 CP1 模型编色；可测试性最好 |
| 2 | **`compose_ambient`（弥散光/氛围层）** | compose_* 工具 | 引擎能力已验证（NOISE/LAYER_BLUR/渐变）；直击评审一指标 #5（非 SOLID fills 占比）与"质感可见"判据 |
